# Wallent Frontend Challenge

## Overview
A financial management dashboard built with Next.js and Material-UI, featuring transaction tracking and financial analytics. This project was developed as part of a coding challenge.

## 🚀 Tech Stack
- Next.js 14
- Material-UI v5
- TypeScript
- React Hook Form + Yup/Zod
- ApexCharts/Recharts for visualizations
- Axios for API calls

## 🛠️ Quick Start

1. Install dependencies:
```bash
pnpm install -f
# or
npm install -f
```

2. Run development server:
```bash
pnpm dev
# or
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## 🎯 Features Implemented
- User authentication (Sign In/Sign Up)
- Dashboard with financial overview
- Transaction management and filtering
- Responsive design for all devices
- Data visualization with charts

## 🏗️ Project Structure
```
src/
├── app/              # Next.js app router pages
├── components/       # React components
├── hooks/           # Custom hooks
└── lib/             # Utilities and configs
```
